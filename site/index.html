Install in a minute.

GK Fitness isn't on the Play Store yet, so Android asks you to confirm the install once.

  1. Download the APK on your phone with the button above. If Chrome asks whether to keep the file, tap Download anyway.

  3. Tap Install. If Play Protect warns that it doesn't recognise the developer, choose More details → Install anyway.
